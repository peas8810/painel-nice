# NICE · Painel Institucional de Extensão, Eventos e Inteligência de Dados

Dashboard interativo do NICE / AlfaUnipac para análise de eventos, extensão e alcance institucional.

O projeto inclui:
- indicadores e filtros por ano, curso, tipo de ação, modalidade, unidade/campus e alcance;
- análise de dados;
- Machine Learning com Random Forest;
- Deep Learning com rede neural MLP;
- simulador preditivo de engajamento;
- segmentação de cursos com K-Means;
- detecção de anomalias com Isolation Forest;
- metodologia e limitações de uso.

A versão pública foi preparada sem e-mails ou nomes de docentes. A inferência dos modelos ocorre localmente no navegador.

Período da base: 2021–2026 (2026 parcial).
